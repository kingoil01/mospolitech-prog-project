\doxysubsection{Подробное описание}
Класс-\/синглтон для управления подключением к базе данных SQLite и выполнения вычислений. 

Обеспечивает авторизацию, регистрацию, хранение прогресса пользователей, а также содержит математическую логику для генерации и проверки серверных задач.
