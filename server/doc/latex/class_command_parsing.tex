\doxysubsection{Подробное описание}
Класс бизнес-\/логики для парсинга и обработки текстовых протокольных команд от клиентов. 

Принимает сырые строки команд, разбивает их на параметры, осуществляет необходимую диспетчеризацию в методы базы данных или вычислительные функции и формирует текстовый ответ.
